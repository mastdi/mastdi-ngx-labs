Welcome to your decentralized fitness vault.

To pull metrics from your body composition history, we need a secure token connection link.

How to acquire your API access token:

  1. Log into your primary fitness metrics database account portal.
  2. Navigate to Account Settings → Developer Tokens.
  3. Generate a new read-scoped token string and copy it.

security Your token is encrypted inside your browser's local storage database and is never sent to an external server.
